# Shelby App — Codex Instructions

## Design System
Always follow the UI/UX Pro Max design system defined in:
.claude/skills/ui-ux-pro-max/SKILL.md

## Animation Stack
- GSAP for scroll and complex SVG animations
- Framer Motion for React component transitions
- 21st.dev MCP for base UI components

## Stack
- Next.js + Tailwind CSS
- TypeScript

## Rules
- Dark mode mandatory on every page
- Touch targets minimum 44x44px
- No gradient buttons, no colored side borders on cards
- Crypto/Web3 dark aesthetic with teal primary accent
